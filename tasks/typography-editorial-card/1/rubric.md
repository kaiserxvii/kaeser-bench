# Evaluation intent

This first task is intentionally narrow. It should make these behaviors easy to inspect later:

- semantic HTML agrees with the visual hierarchy;
- every text element uses a documented type role and token;
- the title remains dominant without making all text large;
- long-form text remains readable at narrow and wide viewports;
- the link has a visible keyboard focus state;
- the implementation contains no external dependencies or arbitrary font values.

This rubric is evaluator-only and is not included in the model context.
