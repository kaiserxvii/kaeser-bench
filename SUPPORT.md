# Support

Kaeser Bench is pre-release software maintained on a best-effort basis.

- Use GitHub Discussions for usage questions, ideas, and open-ended design conversations once
  Discussions is enabled.
- Use the appropriate GitHub issue form for reproducible bugs, scoped features, or benchmark-task
  proposals.
- Use the private process in `SECURITY.md` for vulnerabilities.
- Use the private process in `CODE_OF_CONDUCT.md` for sensitive conduct reports.

Please do not contact individual contributors for private technical support. There are currently no
response-time guarantees.
